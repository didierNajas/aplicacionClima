#  Aplicación del Clima

##  Descripción
Esta aplicación obtiene información meteorológica en tiempo real utilizando la API de **Open-Meteo**.  
El usuario puede consultar la temperatura y condiciones actuales de una ciudad, además de visualizar datos de múltiples ciudades de forma simultánea.

---

##  Funcionalidades principales
-  **Llamada API funcional** para obtener datos del clima.
-  **Manejo de errores**: mensajes claros cuando la API falla o no responde.
-  **Consulta de varias ciudades** en una sola ejecución.
-  **Uso de caché** para optimizar llamadas y mejorar rendimiento.
-  **Pruebas unitarias** que validan el correcto funcionamiento del código.
-  **Documentación básica**: comentarios en el código y archivo README.
-  **Seguridad y ética**: buenas prácticas de codificación segura y uso responsable de código generado por IA.
